# Git 提交规范

## 规则

1. 提交信息用中文写。
2. 动词开头，例如：`修复xxx`、`新增xxx`、`优化xxx`。
3. 单行摘要，尽量短，不加句号结尾。
4. 提交只包含本轮相关改动，不混入无关文件。

## 示例

- `修复补仓比例计算错误`
- `新增 profit trade 中断追踪页面`
- `优化 case-monitor 报表输出对齐`
