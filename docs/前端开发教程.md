超好，我们就用一套你以后可复用的固定流程。

每次新建 Vue+TS 前端项目（最推荐）
到项目根目录
cd 你的项目目录
用 Vite 创建模板
npm create vite@latest frontend -- --template vue-ts
进入前端目录并安装依赖
cd frontend
npm install
启动开发环境
npm run dev
打开终端提示的网址（通常是）
http://127.0.0.1:5173

生产构建（上线前）

npm run build
你可以记住这三个核心命令

创建：npm create vite@latest ... --template vue-ts
开发：npm run dev
打包：npm run build

前端命名规则

- 页面导航、项目名、主标题优先使用中文，不再用 Account Check、Steam Balances、Guadao Report 这类英文项目名。
